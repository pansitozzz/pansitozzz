# Plan profesional del portafolio

Este repositorio de perfil está orientado a presentar un perfil junior/preprofesional en Ingeniería de Sistemas con foco principal en desarrollo de software/backend y una ruta secundaria hacia datos/automatización.

## Prioridad de proyectos

1. **incidentes-practica** — Django, PostgreSQL, Docker, lógica de negocio, reportes y testing.
2. **apibiblioteca** — Java, Spring Boot, Angular, PostgreSQL, JWT, Swagger y testing.
3. **trs-notificaciones** — Django, MySQL y experiencia de despliegue real en producción.
4. **pastadental** — Unity/C#, útil como evidencia de adaptabilidad técnica, pero no es el foco principal.

## Próximas mejoras cuando sea posible ejecutar los proyectos

- Añadir 2–3 capturas reales por repositorio.
- Incluir una sección breve de arquitectura o flujo principal.
- Confirmar comandos de instalación y ejecución en un entorno limpio.
- Añadir badges de CI/tests solo si existe automatización real.

## Objetivo de postulación

Priorizar vacantes de:

- Practicante de Desarrollo de Software
- Practicante Backend / Backend Junior
- Software Engineer Intern / Junior
- Practicante de Sistemas orientado a desarrollo
- Automatización de procesos / aplicaciones internas
- Implementación o soporte de aplicaciones empresariales

Como segunda línea, postular a Data Engineering / ETL cuando la vacante valore Python + SQL y no exija experiencia avanzada en herramientas BI o cloud.
